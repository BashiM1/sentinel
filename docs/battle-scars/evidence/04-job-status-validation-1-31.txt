=== Original (naive) test helper that broke ===
func markJobComplete(ctx context.Context, job *batchv1.Job) {
    job.Status.Succeeded = 1
    job.Status.Conditions = append(job.Status.Conditions, batchv1.JobCondition{
        Type:               batchv1.JobComplete,
        Status:             corev1.ConditionTrue,
        LastProbeTime:      metav1.Now(),
        LastTransitionTime: metav1.Now(),
    })
    Expect(k8sClient.Status().Update(ctx, job)).To(Succeed())   // <-- 422
}

=== Fix ===
markJobComplete now sets StartTime, CompletionTime, and prepends
JobSuccessCriteriaMet=True before JobComplete=True.
markJobFailed sets StartTime and prepends JobFailureTarget=True
before JobFailed=True.

See `markJobComplete` and `markJobFailed` in
internal/controller/governancescan_controller_test.go.
