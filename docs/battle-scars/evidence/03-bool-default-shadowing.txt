=== Original API definition (the bug) ===
type ApprovalConfig struct {
    // +kubebuilder:default=true
    // +optional
    Required bool `json:"required,omitempty"`
}

The chain:
  - Go zero value: Required = false
  - JSON marshal with omitempty: field absent from request body
  - apiserver sees no `required` field, applies default=true
  - stored object: Required = true
  - Reconciler's `if scan.Spec.Approval.Required { /* waitApproval */ }` fires
  - Test asserts Approved, gets AwaitingApproval. Failure.

=== Fix (api/v1alpha1/governancescan_types.go) ===
type ApprovalConfig struct {
    // +kubebuilder:default=true
    // +optional
    Required *bool `json:"required,omitempty"`
}

func (a ApprovalConfig) IsRequired() bool {
    if a.Required == nil { return true }   // matches kubebuilder default
    return *a.Required
}

The pointer + omitempty preserves the explicit-false signal: nil means
"unset, apply default" and a non-nil pointer always serialises (true OR false).
